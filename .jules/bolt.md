## 2025-02-13 - [Infinite Scroll Sentinel Eager Loading Mitigation]
**Learning:** In the infinite-scroll `SearchResults` page, the custom `useIntersectionObserver` hook was previously configured to disconnect on first intersection by default (`triggerOnce?: boolean` was missing). While this is perfect for static components like `LazyImage` and initial home row loads to minimize DOM overhead, an infinite scroll sentinel must repeatedly detect entering and exiting the viewport. When implemented incorrectly or without resetting its intersection state when out of view, the sentinel can trigger continuous, eager API requests even when not visible.
**Action:** Extend the custom `useIntersectionObserver` hook to support a `triggerOnce?: boolean` parameter (defaulting to `true` to keep existing behavior optimized). When `triggerOnce` is `false`, reset the intersection state to `false` when the observed element leaves the viewport. Explicitly pass `{ triggerOnce: false }` for scroll-sentinels like the one in `SearchResults` to prevent redundant background fetching.
